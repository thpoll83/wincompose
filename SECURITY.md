# Security policy

This repository is the PolyKybd fork of
[WinCompose](https://github.com/samhocevar/wincompose).

## Reporting a vulnerability

Report a suspected vulnerability privately, through GitHub:
<https://github.com/thpoll83/wincompose/security/advisories/new>
(the "Report a vulnerability" button on the Security tab).
Do not open a public issue, pull request or discussion for it.

Report it here even when the problem comes from code inherited from upstream
WinCompose. Upstream is not actively maintained, so this fork fixes such problems
itself. We also tell the upstream project about them.

Include:

- what the problem is and what an attacker can do with it,
- the steps to reproduce it,
- the version (About tab) and your Windows version.

## Supported versions

Only the latest published `PK-X.Y.Z` release receives security fixes.

## What happens next

This fork is maintained by one person in their spare time. Reports are handled on a
reasonable-effort basis, without a fixed response time. Please allow 90 days for a
fix before you disclose the problem publicly. Reporters are credited in the published
advisory unless they ask not to be.
